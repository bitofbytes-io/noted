Send to Noted: share a PDF from Safari straight into a new draft

Two new pieces. An Account dialog off the masthead where each user sets up (or turns off) their one Shortcut token, and an iOS Shortcut that posts the shared PDF to Noted with that token. Each shared PDF starts a new draft, prefilled when the filename names an IMSLP work. The Shortcut is a signed template Noted serves at /send-to-noted.shortcut.

Replace the token? The Shortcut on your iPad stops working until you paste the new one.

Get the Shortcut againYou’ll need your token; if you don’t have it, tap Replace.

  • The token is 43 characters (32 random bytes, base64url). Noted stores only its SHA-256, like user_sessions.token_hash. Copy uses the clipboard API and falls back to selecting the text.
  • Replace and Turn off confirm inline (the dialog shows the confirm block in C); there is no confirm(). Replace = delete + create in one transaction, then the dialog goes to state B.
  • Sign out does not touch the token; the Shortcut is tied to the device, not the session. Turning it off is the only way to invalidate it.
  • Get the Shortcut downloads /send-to-noted.shortcut, a signed template with a placeholder token; Shortcuts asks for the real token on import. There is no iCloud link: a personal Shortcut's link carries its token. Get the Shortcut again in C is for a second device.

  • When the toggle is on, the Shortcut opens https://noted.bitofbytes.io/prepare/<draftId> after the notification, which resumes the draft with the PDF attached and Continue enabled.

Server

What POST /api/shortcut/import does with the file

1Bearer token → user. Size and PDF checks, same as the normal upload.
2Filename starts with IMSLP<number>-?
→Yes. Special:ReverseLookup/<number> → 302 → work page URL (cached 24 h; shares the IMSLP limiter and breaker).
→Found: new draft with link, title and composer prefilled (IMSLP provenance). Existing drafts for the work are never touched.
→No, or lookup failed: new draft titled from the filename, no provenance.
3Upload through the existing draft-source path. Reply 201 {draftId, draftPath, title, composer, filename, headline, message}; message is always "New draft created."
  • The lookup never fails the import; without a work the draft is titled from the filename. The user can delete a stray draft from the library, and drafts expire after seven idle days.
  • Per-user limit: 10 imports a minute. One info log line per accepted import (user id), never the filename.
